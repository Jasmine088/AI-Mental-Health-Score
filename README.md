# AI Mental Health Score Predictor

An end-to-end Machine Learning project that predicts a mental health score based on lifestyle, academic, and social media usage factors.

##  Features

- Machine Learning based mental health score prediction
- Data preprocessing and feature engineering
- Trained ML model saved using Joblib
- FastAPI backend for predictions
- Pydantic data validation
- HTML, CSS & JavaScript frontend
- Interactive API documentation with Swagger

##  Tech Stack

**Machine Learning:** Python, Pandas, NumPy, Scikit-learn, Joblib  
**Backend:** FastAPI, Uvicorn, Pydantic  
**Frontend:** HTML, CSS, JavaScript  
**Tools:** VS Code, Git, GitHub
